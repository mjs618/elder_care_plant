# 前端架构分析

## 1. 概述

前端采用Vue 3 + Vite + Element Plus技术栈，实现了组件化、模块化的前端架构。本文档分析前端代码结构、组件设计、状态管理等方面。

## 2. 技术栈

| 技术 | 版本 | 用途 |

| Vue | 3.x | 前端框架 |
| Vite | 4.x | 构建工具 |
| Element Plus | 2.x | UI组件库 |
| Pinia | 2.x | 状态管理 |
| Vue Router | 4.x | 路由管理 |
| ECharts | 5.x | 图表库 |

### 6.2 路由守卫

```javascript
// router/permission.js
router.beforeEach(async (to, from, next) => {
  const userStore = useUserStore()
  const permissionStore = usePermissionStore()
  
  if (to.meta.requiresAuth !== false) {
    if (!userStore.token) {
      next('/login')
    } else {
      if (permissionStore.routes.length === 0) {
        await permissionStore.generateRoutes(userStore.roles)
        // 动态添加路由
      }
      next()
    }
  } else {
    next()
  }
})
```

## 7. API封装

### 7.1 请求封装

```javascript
// utils/request.js
import axios from 'axios'
import { useUserStore } from '@/stores/user'

const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 30000
})

request.interceptors.request.use(
  config => {
    const userStore = useUserStore()
    if (userStore.token) {
      config.headers.Authorization = `Bearer ${userStore.token}`
    }
    return config
  },
  error => Promise.reject(error)
)

request.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // Token过期处理
    }
    return Promise.reject(error)
  }
)

export default request
```

### 9.2 使用组合式函数

```javascript
// 建议提取通用逻辑为组合式函数
// composables/useAssessment.js
import { ref, computed } from 'vue'
import { assessmentApi } from '@/api/assessment'

export function useAssessment(scaleName) {
  const loading = ref(false)
  const questions = ref([])
  const answers = ref({})
  const result = ref(null)
  
  const progress = computed(() => {
    const answered = Object.keys(answers.value).length
    return Math.round((answered / questions.value.length) * 100)
  })
  
  const fetchQuestions = async () => {
    loading.value = true
    try {
      const data = await assessmentApi.getScaleQuestions(scaleName)
      questions.value = data
    } finally {
      loading.value = false
    }
  }
  
  const submitAssessment = async (patientId) => {
    loading.value = true
    try {
      result.value = await assessmentApi.submit({
        scale_name: scaleName,
        patient_id: patientId,
        answers: answers.value
      })
      return result.value
    } finally {
      loading.value = false
    }
  }
  
  return {
    loading,
    questions,
    answers,
    result,
    progress,
    fetchQuestions,
    submitAssessment
  }
}
```
