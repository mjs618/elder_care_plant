# 健康管理模块分析

## 1. 模块概述

健康管理模块提供老年人健康数据管理功能，包括健康档案、用药管理、运动康复、营养管理、生命体征监测、健康预警等核心功能。模块支持健康数据的可视化展示和趋势分析。

## 2. 功能架构

### 2.1 功能清单

| 功能项 | 描述 | 状态 |
|--------|------|------|
| 健康档案 | 个人健康信息管理 | ✅ 已实现 |
| 生命体征 | 血压、血糖、心率等监测 | ✅ 已实现 |
| 用药管理 | 药物信息、用药提醒 | ✅ 已实现 |
| 运动康复 | 运动计划、康复训练 | ✅ 已实现 |
| 营养管理 | 饮食记录、营养分析 | ✅ 已实现 |
| 健康预警 | 异常数据预警通知 | ✅ 已实现 |

```python
class HealthData(Base):
    """健康数据表"""
    __tablename__ = "health_data"
    
    id = Column(Integer, primary_key=True)
    patient_id = Column(Integer, ForeignKey("patients.id"), nullable=False)
    record_date = Column(Date, nullable=False, default=date.today)
    
    # 生命体征
    systolic_bp = Column(Integer)  # 收缩压
    diastolic_bp = Column(Integer)  # 舒张压
    heart_rate = Column(Integer)  # 心率
    blood_glucose = Column(Float)  # 血糖
    blood_glucose_type = Column(String(20))  # 空腹/餐后
    temperature = Column(Float)  # 体温
```

```python
# 建议增加实时预警服务
from typing import Callable, List
import asyncio

class RealTimeAlertService:
    """实时预警服务"""
    
    def __init__(self):
        self.rules: List[AlertRule] = []
        self.callbacks: List[Callable] = []
    
    async def check_and_alert(self, patient_id: int, health_data: dict):
        """检查数据并触发预警"""
        alerts = []
        
        for rule in self.rules:
            if not rule.is_active:
                continue
            
            metric_value = health_data.get(rule.metric_type)
            if metric_value is None:
                continue
            
            is_triggered = self._evaluate_rule(rule, metric_value)
            
            if is_triggered:
                alert = await self._create_alert(patient_id, rule, metric_value)
                alerts.append(alert)
                
                # 触发回调
                for callback in self.callbacks:
                    await callback(alert)
        
        return alerts
    
    def _evaluate_rule(self, rule: AlertRule, value: float) -> bool:
        """评估规则"""
        if rule.condition_type == 'greater_than':
            return value > rule.threshold_max
        elif rule.condition_type == 'less_than':
            return value < rule.threshold_min
        elif rule.condition_type == 'range':
            return value < rule.threshold_min or value > rule.threshold_max
        return False
```
