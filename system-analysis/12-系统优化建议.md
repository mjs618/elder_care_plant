# 系统优化建议

## 1. 概述

本文档汇总系统各模块的优化建议，从架构、性能、安全、可维护性等多个维度提出改进方案。

## 2. 架构优化

### 2.1 模块解耦

**问题**: 部分模块间存在循环依赖，耦合度较高

**建议**:
```
1. 引入事件驱动架构，使用消息队列解耦模块
2. 定义清晰的模块边界和接口
3. 使用依赖注入替代直接导入
```

**示例**:
```python
# 使用事件总线解耦模块
class EventBus:
    def __init__(self):
        self._handlers = defaultdict(list)
    
    def subscribe(self, event_type: str, handler: Callable):
        self._handlers[event_type].append(handler)
    
    async def publish(self, event_type: str, data: Any):
        for handler in self._handlers[event_type]:
            await handler(data)

# 使用示例
event_bus = EventBus()

# 评估模块发布事件
await event_bus.publish("assessment_completed", {
    "patient_id": patient_id,
    "assessment_id": assessment_id
})

# 健康模块订阅事件
@event_bus.subscribe("assessment_completed")
async def update_health_records(data):
    # 更新健康记录
    pass
```

### 2.2 服务层重构

**问题**: 服务文件存在冗余（如knowledge_service.py/enhanced/advanced）

**建议**:
```
1. 合并功能重叠的服务文件
2. 使用策略模式支持不同实现
3. 统一服务接口定义
```

**示例**:
```python
# 统一的知识服务
class KnowledgeService:
    def __init__(self, db: Session, config: ServiceConfig):
        self.db = db
        self.retriever = self._create_retriever(config.retrieval_method)
    
    def _create_retriever(self, method: str) -> Retriever:
        retrievers = {
            'keyword': KeywordRetriever(),
            'semantic': SemanticRetriever(),
            'hybrid': HybridRetriever()
        }
        return retrievers.get(method, HybridRetriever())
```

**问题**: 路由文件过多，部分功能重叠

**建议**:

```
1. 合并相似路由（如learning_home/enhanced_learning_home）
2. 使用API版本控制
3. 统一响应格式
```

**示例**:

### 3.2 缓存优化

| 优化项 | 描述 | 优先级 |
|--------|------|--------|
| Redis缓存 | 缓存热点数据 | 高 |
| 本地缓存 | 使用LRU缓存减少Redis访问 | 中 |
| 缓存预热 | 系统启动时预热常用数据 | 中 |
| 缓存失效 | 合理设置缓存过期策略 | 中 |

**示例**:
```python
# 多级缓存实现
from functools import lru_cache
import redis

class CacheService:
    def __init__(self):
        self.redis = redis.Redis()
    
    @lru_cache(maxsize=1000)
    def get_local(self, key: str):
        """本地缓存"""
        return self.redis.get(key)
    
    async def get(self, key: str, loader: Callable = None):
        """获取缓存，支持自动加载"""
        # 先查本地缓存
        value = self.get_local(key)
        if value:
            return value
        
        # 再查Redis
        value = self.redis.get(key)
        if value:
            return value
        
        # 加载数据
        if loader:
            value = await loader()
            self.set(key, value)
            return value
        
        return None
```

## 4. 安全优化

### 4.1 认证授权

| 优化项 | 描述 | 优先级 |
|--------|------|--------|
| Token刷新 | 实现Token自动刷新机制 | 高 |
| 密码强度 | 增加密码强度校验 | 高 |
| 登录限制 | 增加登录失败次数限制 | 高 |
| 会话管理 | 实现会话超时和强制登出 | 中 |

**示例**:
```python
# Token刷新机制
from datetime import datetime, timedelta
import jwt

class TokenService:
    SECRET_KEY = "your-secret-key"
    ACCESS_TOKEN_EXPIRE = 30  # 分钟
    REFRESH_TOKEN_EXPIRE = 7  # 天
    
    def create_tokens(self, user_id: int) -> dict:
        now = datetime.utcnow()
        
        access_token = jwt.encode({
            "sub": user_id,
            "type": "access",
            "exp": now + timedelta(minutes=self.ACCESS_TOKEN_EXPIRE)
        }, self.SECRET_KEY)
        
        refresh_token = jwt.encode({
            "sub": user_id,
            "type": "refresh",
            "exp": now + timedelta(days=self.REFRESH_TOKEN_EXPIRE)
        }, self.SECRET_KEY)
        
        return {
            "access_token": access_token,
            "refresh_token": refresh_token,
            "token_type": "bearer"
        }
    
    def refresh_access_token(self, refresh_token: str) -> str:
        payload = jwt.decode(refresh_token, self.SECRET_KEY)
        if payload["type"] != "refresh":
            raise ValueError("Invalid token type")
        
        return self.create_tokens(payload["sub"])["access_token"]
```

**示例**:
```python
# 敏感数据加密
from cryptography.fernet import Fernet

class EncryptionService:
    def __init__(self, key: bytes):
        self.cipher = Fernet(key)
    
    def encrypt(self, data: str) -> str:
        return self.cipher.encrypt(data.encode()).decode()
    
    def decrypt(self, encrypted: str) -> str:
        return self.cipher.decrypt(encrypted.encode()).decode()

# 使用示例
class Patient(Base):
    id_card = Column(String(100))  # 存储加密后的数据
    
    @property
    def id_card_plain(self):
        return encryption_service.decrypt(self.id_card)
    
    @id_card_plain.setter
    def id_card_plain(self, value):
        self.id_card = encryption_service.encrypt(value)
```

## 7. 总结

系统整体设计合理，功能完善。主要优化方向：
1. **架构层面**: 模块解耦、服务整合、API规范化
2. **性能层面**: 数据库优化、缓存策略、前端优化
3. **安全层面**: 认证授权、数据安全、日志脱敏
4. **可维护性**: 代码规范、测试覆盖、监控告警

建议按照短期、中期、长期的路线图逐步实施优化，确保系统稳定运行的同时持续改进。
